계산 방식

1. 정규화: z₀ = ([x, y, Re] − input_mean) / input_std

2. 각 층: z ← W·z + b (Linear) 후 활성화 함수 (Tanh / ReLU / LeakyReLU / Sigmoid, JSON의 layers 순서 그대로)

3. 역정규화: [u, v, p] = z_out · output_std + output_mean

4. 50×50 셀 중심 x, y = (index + 0.5)/50, 행은 y가 증가하는 순서. Re를 바꿀 때 CFD 계산·재학습·저장 그림·CFD 보간은 하지 않습니다. 유선은 신경망이 예측한 u, v 격자를 따라 그립니다.
